# 📝 MERN Todo App — Full Stack (Monorepo)

A full-stack **Todo Application built using the MERN stack** with a clean modern UI, drag-and-drop reordering, dark/light theme toggle, and cloud-hosted database.

This repo contains both the **frontend (React + Vite)** and **backend (Node + Express + MongoDB)** inside a single monorepo.

## 🏗 Tech Stack

### 🌐 Frontend
- React (Vite)
- Tailwind CSS
- Framer Motion (animations)
- @dnd-kit (Drag & Drop)
- Axios / Fetch API

### 🔌 Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- CORS
- Dotenv

### ☁ Hosting
- Vercel — *Frontend*
- Render — *Backend*
- MongoDB Atlas — *Database*

## 🔧 Installation (Run Locally)

### 1️⃣ Clone the repo
```bash
git clone https://github.com/YOUR_USERNAME/Todo-App.git
cd Todo-App

2️⃣ Backend Setup
cd backend
npm install


Create .env file:

MONGO_URI=your_mongodb_uri
PORT=5000


Run backend:

npm run dev

3️⃣ Frontend Setup
cd ../frontend
npm install
npm run dev


App runs on:

http://localhost:5173
